카루메 뮤직 시작하기

유튜브 링크를 추가해서 먼저 음악을 들어 보세요. 검색을 사용하려면 API 키를 한 번 설정하면 됩니다.

1. API 키 없이 노래 추가하기

  1. YouTube에서 원하는 영상의 공유 → 링크 복사를 선택합니다.
  2. 플레이어의 + 버튼을 누르고 이용 안내에 동의합니다.
  3. 영상 링크를 붙여 넣고 검색 → 추가를 누릅니다.
  4. 검색창을 닫고 곡 목록에서 곡을 선택하거나 가운데 재생 버튼을 누릅니다.

영상 정보 조회가 차단되면 영상 ID가 제목으로 표시됩니다. 재생이 시작되면 YouTube에서 받은 실제 제목으로 바뀝니다. 외부 재생이 금지된 영상은 YouTube에서 열어야 합니다.

2. YouTube 검색 키 발급하기

  1. Google Cloud Console에 로그인하고 프로젝트를 생성하거나 선택합니다.
  2. API 및 서비스 → 라이브러리에서 YouTube Data API v3를 찾아 사용 설정합니다.
  3. API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키를 선택합니다.
  4. 키의 애플리케이션 제한사항을 웹사이트로 설정합니다. 실제 사용하는 사이트의 출처와 와일드카드 주소를 허용합니다. GitHub Pages라면 https://YOURNAME.github.io와 https://YOURNAME.github.io/*를 넣습니다. 현재 미리보기 사이트에서 쓰려면 그 사이트의 주소도 별도로 넣습니다.
  5. API 제한사항 → 키 제한에서 YouTube Data API v3만 선택하고 저장합니다.
  6. 플레이어에서 + → 검색 설정 → API 키에 키를 입력하고 저장합니다. 이제 곡명이나 아티스트로 검색할 수 있습니다.

키는 이 탭의 세션에만 저장되며, GitHub 소스나 앱에 내장되지 않습니다. 브라우저에서 쓰는 키는 사용자에게 보일 수 있으므로 웹사이트/API 제한을 꼭 설정하세요. 키를 대화나 공개 저장소에 붙여 넣지 마세요.

검색이 거부되면 API 사용 설정, 허용 웹사이트 주소, 검색 할당량을 확인하세요. 할당량이 다 쓰였을 때에도 링크 추가는 이용할 수 있습니다. 키를 없애려면 입력칸을 비우고 저장하세요.

3. 내 GitHub에 배포하기

  1. 제공된 소스 ZIP을 압축 해제합니다.
  2. GitHub에서 새 저장소를 만듭니다. 이름은 karume-music 등 원하는 이름을 사용하세요. GitHub 무료 계정이라면 Pages를 사용할 공개 저장소를 선택합니다.
  3. 압축 해제한 폴더의 내용 전체를 저장소의 main 브랜치 최상위에 업로드합니다. package.json, app, public이 최상위에 있어야 합니다. .github/workflows/pages.yml, .npmrc, .openai/hosting.json, pnpm-lock.yaml도 포함해야 합니다. 브라우저 업로드에서 점으로 시작하는 폴더가 누락되면 GitHub Desktop으로 폴더 전체를 커밋·게시하거나 해당 경로에 파일을 생성합니다.
  4. 저장소 Settings → Pages → Build and deployment → Source를 GitHub Actions로 선택합니다.
  5. Actions → Publish music player to GitHub Pages → Run workflow를 실행합니다. 첫 업로드 때 Pages 설정이 안 되어 실패했어도 설정 후 다시 실행하면 됩니다.
  6. 작업이 성공하면 Settings → Pages에 사이트 주소가 표시됩니다. 저장소 이름에 맞는 경로는 자동으로 적용됩니다.

노션에 삽입할 주소: https://bbusiku.github.io/karume-music/?embed=1

4. 노션에 플레이어 넣기

  1. 위 GitHub Pages 배포를 완료합니다. 로그인 없이 열리는 Pages 주소를 사용하세요.
  2. 주소 끝에 ?embed=1을 붙입니다. 예: https://YOURNAME.github.io/karume-music/?embed=1
  3. 노션 페이지의 빈 줄에서 /embed를 입력하고 임베드 블록을 선택합니다.
  4. 위 URL을 붙여 넣고 링크 임베드를 선택합니다. HTML iframe 코드가 아니라 URL을 넣습니다.
  5. 블록 가장자리를 끌어 넓힙니다. 두 칸 디자인은 가로 700px·높이 480px 정도부터 권장하며, 좁은 칼럼에서는 세로 배치가 되어 더 높은 블록이 필요합니다.
  6. 노션 안의 + 버튼으로 곡을 추가하고 재생 버튼을 직접 누릅니다.

이전에 제공한 로그인용 비공개 Sites 미리보기 대신, 공개 GitHub Pages 주소를 사용하세요. 노션 데스크톱/모바일 앱에서는 외부 로그인이 필요한 임베드가 작동하지 않을 수 있습니다.

노션 안의 브라우저 저장소는 외부 브라우저와 분리되거나 저장이 제한될 수 있어 곡 목록·API 키를 다시 설정해야 할 수 있습니다. API 키의 웹사이트 제한은 실제 플레이어의 GitHub Pages 주소로 설정합니다. 검색 키를 임베드 URL에 넣지 마세요. 자동 재생 및 일부 YouTube 영상은 노션/브라우저의 정책에 따라 제한될 수 있으며, 노션 안에서의 음향 재생은 아직 실기기 검증하지 않았습니다.

노션 공식 임베드 안내

버튼 동작

  • 곡 목록: 곡을 눌러 재생합니다. 전체 곡/즐겨찾기 탭과 각 곡의 더 보기 메뉴를 사용할 수 있습니다.
  • 하트: 한 번 누르면 즐겨찾기 등록, 다시 누르면 해제합니다.
  • 셔플: 켜면 현재 곡 다음부터 순서를 섞고, 끄면 추가한 순서로 돌아옵니다.
  • 이전/다음: 현재 재생 순서에서 이전·다음 곡으로 이동합니다.
  • 반복: 한 곡 반복 → 전곡 반복 → 반복 해제. 반복 해제에서는 현재 곡이 끝나면 멈춥니다.
  • 위쪽 슬라이더: 음량. 아래쪽 슬라이더: 재생 위치.

영상은 보이는 공식 YouTube 플레이어에서 재생됩니다. 목록·검색창을 열거나 다른 탭으로 이동하면 일시정지됩니다. 브라우저가 자동 재생을 막으면 재생 버튼을 한 번 더 눌러 주세요. 기기·브라우저별로 곡 목록과 즐겨찾기가 각각 저장되며 자동 동기화되지 않습니다.
